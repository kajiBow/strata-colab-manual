# GeminiAIProで無検閲LLMを動かす

Google AI Pro の特典で使える **Google Colab の A100** 上に、大規模モデル **Qwen3.8-Flash-Next** を **Strata** で構築し、無検閲化した状態で **Web UI / OpenAI 互換 API** として使うためのガイドです。

Colab は本来、ノートブックを対話的に使うための環境です。API サーバーとしてそのまま常駐させると短時間でセッションが回収されますが、キープアライブと監視を組み合わせることで、Uncensored 版でも **取得から6時間到達** を確認しました。

---

## このガイドでできること

- Colab A100（40GB）＋ RAM 83GB で Qwen3.8-Flash-Next IQ3_S を動かす
- Cloudflare クイックトンネル経由で Web UI と OpenAI 互換 API を公開する
- コンテキスト長 262,144 トークンで利用する
- API キーでアクセスを保護する
- カーネルを実行状態に保つキープアライブで、セッション回収を遅らせる
- Muse などの AI エージェントに、手順書を渡して構築を任せる

## 最重要ポイント：無検閲化はモデルの重みではない

このモデルの「abliterated」版 GGUF の重みは、配布元の説明では公式版と同一です。無検閲化の実体は、Strata に同梱された拒否方向ベクトルを使う **experimental speed projection** です。

そのため、Uncensored 版を構築するときは、setup で次の指定が必須です。

```text
--experimental-speed-projection on
```

これを付け忘れると、モデルファイルは Uncensored 版でも、応答は公式版と同様に拒否寄りになります。詳細は [AI用プロンプト（Uncensored版）](prompt-uncensored.md) を参照してください。

## 仕組み

```text
あなたの PC / スマホ
   │  HTTPS（API / Web UI）
   ▼
Cloudflare クイックトンネル
（https://*.trycloudflare.com）
   │
   ▼
Google Colab VM
（A100-SXM4-40GB / RAM 83GB）
   ├─ Strata サーバー（port 8081）
   │    └─ Qwen3.8-Flash-Next IQ3_S
   └─ cloudflared

管理側（Muse の VM）
   ├─ google-colab-cli：セッション取得・構築・操作
   ├─ キープアライブ監督：短い実行セルを接続し直し続ける
   └─ 監視：セッション喪失の検知と通知
```

## 接続情報

構築が完了すると、次の情報で利用できます。トンネル URL は構築ごとに変わります。

| 項目 | 値 |
|---|---|
| Base URL | `https://<トンネルURL>/v1` |
| Web UI | `https://<トンネルURL>/` |
| モデル名 | `qwen3.8-flash-next-iq3_s` |
| API キー | 構築時に設定したキー |
| コンテキスト | 262,144 トークン（入力＋出力の合計） |
| 思考レベル | 既定は high（リクエストや Web UI で変更可能） |

Web UI で API キーを入力する場所は、画面上部の **About → Settings → API key** です。

## コストと利用可能時間

計算資源は、生成量ではなく **接続時間** によって消費されます。

| 項目 | 実測・目安 |
|---|---|
| A100 の消費 | 6.73 コンピュートユニット／時 |
| Google AI Pro の月次付与 | 約100〜110 ユニット |
| A100 の利用可能時間 | 月あたり約15〜16時間 |
| ユニットの有効期限 | 90日（日次回復はしない） |

使い終わったら必ず `colab stop` でセッションを止めてください。接続したままでは、使っていなくてもユニットが減り続けます。

## 実測の記録

| 構築 | モデル | 延命策 | 結果 |
|---|---|---|---|
| strata1（2026-11-12） | Uncensored | なし | 約87分 |
| strata2（2026-11-12） | 公式 | なし | 約48分 |
| strata3（2026-11-12） | 公式 | 短い exec を約3.5分ごと | 約111〜144分 |
| strata4（2026-11-13） | 公式 | チャンク方式セル＋監督＋ウォッチドッグ | 約4時間42分（手動停止） |
| strata5（2026-11-13） | Uncensored | チャンク方式セル＋監督＋監視 | **取得から6時間到達を確認** |

## 注意点

- セッションはいずれ落ちます。数時間単位の利用を前提にし、長時間の常駐ホストには向きません。
- A100 は混雑時に取得できないことがあります。実測では、平日朝〜午前が比較的空いていました。
- トンネル URL と API キーはセットで管理してください。URL が変わるため、ブックマークは構築ごとに更新が必要です。
- Colab の規約上、Web サービス提供はグレーな領域です。利用は自己責任でお願いします。
