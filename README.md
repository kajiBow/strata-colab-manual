# Strata × Google Colab A100 運用マニュアル

Google Colab の A100 で大規模モデル **Qwen3.8-Flash-Next** を **Strata** で動かし、Cloudflare トンネル経由で **OpenAI 互換 API と Web UI** として使うためのマニュアルです。

Colab の無料/有料ランタイムは本来「ノートブックを対話的に使う」ためのもので、API サーバーとして常駐させる使い方ではセッションが短時間で回収されてしまいます。本マニュアルの方式（カーネルを意図的に忙しく保つキープアライブ）で、**約4時間42分の連続稼働**を実測しました（対策なしでは 48分〜2.4時間で消滅）。

## 構成

```
あなたのPC / スマホ
   │  https (API / Web UI)
   ▼
Cloudflare クイックトンネル (https://*.trycloudflare.com)
   │
   ▼
Google Colab VM (A100-SXM4-40GB / RAM 83GB)
   ├─ Strata サーバー (port 8081) … Qwen3.8-Flash-Next IQ3_S
   └─ cloudflared … トンネル公開

管理側 (Muse の VM)
   ├─ google-colab-cli … セッション取得・構築・操作
   ├─ キープアライブ監督 … 約8分のセルを接続し直し続ける
   └─ 監視 (15分ごと) … 喪失検知と通知
```

## 使うときの接続情報

| 項目 | 値 |
|---|---|
| Base URL | `https://<トンネルURL>/v1`（構築ごとに変わる） |
| モデル名 | `qwen3.8-flash-next-iq3_s` |
| API キー | 構築時に設定したキー（Web UI は About → Settings の API key 欄にも入力） |
| Web UI | `https://<トンネルURL>/` |
| コンテキスト | 262,144 トークン（入力+出力の合計） |
| 思考レベル | 既定 high（リクエストや Web UI の Chat settings で変更可） |

## コスト（コンピュートユニット）

- A100 の消費は **6.73 ユニット/時**（実測。生成量ではなく**接続時間**で減る）
- Google AI Pro の月次付与は約100〜110 ユニット → **月あたり約15〜16時間**が目安
- ユニットは月次付与・90日で失効。**日次回復はしない**
- 使い終わったら必ずセッションを止める（`colab stop`）。止めない限り消費は続く

## 注意点

- **セッションはいずれ落ちます**。数時間単位の利用を前提にし、長時間の常駐ホストには向きません。
- トンネルの URL は構築ごとに変わります。URL が漏れても API キーが無いと使えませんが、URL とキーはセットで管理してください。
- 取得は平日朝〜午前が比較的空いています。混雑時は A100 が取れないことがあります。
- Colab の規約上、Web サービス提供はグレーな領域です。自己責任でどうぞ。
